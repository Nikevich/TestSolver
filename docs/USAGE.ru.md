# TestSolver — инструкция по использованию

TestSolver открывает страницу теста во встроенном браузере, читает вопрос и варианты ответа, спрашивает локальную модель (Ollama или `opencode`), выбирает ответ и нажимает «Продолжить». Поддерживаются вопросы с одним и несколькими вариантами, а также с текстовым полем ввода — число, слово или последовательность номеров.

**English version:** [USAGE.en.md](USAGE.en.md) · **Обзор проекта:** [../README.md](../README.md)

---

## Быстрая шпаргалка

1. Запустить `TestSolver.exe`.
2. Вставить адрес теста в строку сверху → **Перейти** и войти в тест.
3. В панели справа выбрать бэкенд и модель, нажать **Проверить связь с моделью**.
4. Нажать **Старт** (или `Ctrl` + `Shift` + `S`).
5. Следить за прогрессом; при необходимости — **Стоп**.

---

## 1. Что нужно

| Требование | Детали |
|---|---|
| Операционная система | Windows 10 или 11, 64-bit |
| Модель | Установленная **Ollama** с нужными моделями **или** CLI **opencode** |
| Интернет | Для страницы теста; для облачных моделей opencode — доступ к провайдеру |
| Node.js, Python, npm | **Не нужны** — Chromium и Node уже внутри приложения |

Для работы без интернета подойдёт Ollama с локальной моделью. Для облачной модели через opencode нужен интернет и авторизация в opencode.

## 2. Установка

### Вариант А. Инсталлятор (рекомендуется)

1. Запустить `TestSolver-<версия>-x64.exe`.
2. Если Windows покажет SmartScreen («Windows защитила ваш компьютер»): **Подробнее** → **Выполнить всё равно**. Это нормально для неподписанного exe.
3. Выбрать папку установки, дождаться завершения. Создаются ярлыки в меню «Пуск» и на рабочем столе.
4. Запускать через ярлык.

Файлы данных:

| Что | Где |
|---|---|
| Настройки | `%APPDATA%\TestSolver\config.json` |
| Журналы | `%APPDATA%\TestSolver\logs\` |
| Сессия сайта (логины) | `%APPDATA%\TestSolver\Partitions\testsolver\` |

Удаление — «Параметры» → «Приложения» → TestSolver. Настройки и журналы при удалении остаются; при желании удалите папку `%APPDATA%\TestSolver` вручную.

### Вариант Б. Portable

- Один файл `TestSolver-<версия>-portable.exe`, установка не нужна.
- При каждом запуске распаковывается во временную папку, поэтому стартует дольше инсталлятора (обычно 10–40 секунд).
- `config.json` и папка `logs` создаются **рядом с exe**: удобно носить на флешке и хранить настройки вместе с программой.
- Не запускайте два экземпляра одновременно и не перемещайте exe во время работы.

## 3. Первый запуск

Окно разделено на три части.

**Сверху — панель навигации:**

| Элемент | Назначение |
|---|---|
| ← / → / ↻ | Назад, вперёд, обновить страницу |
| Адресная строка | Адрес страницы теста |
| **Перейти** | Открыть введённый адрес |
| **Открыть тест** | Открыть сохранённый стартовый URL |
| ↗ | Открыть текущую страницу в системном браузере |

**Слева — сайт теста.** Логин и пароль вводятся прямо в этом окне; сессия сохраняется между запусками, поэтому повторно входить обычно не требуется.

**Справа — панель с вкладками:**

| Вкладка | Что там |
|---|---|
| **Управление** | Бэкенд, модель, задержка, лимит вопросов, «Старт» / «Стоп», прогресс |
| **Настройки** | Все параметры приложения, сброс к умолчаниям, папка логов |
| **Лог** | Журнал в реальном времени, кнопка «HTML страницы» для диагностики |
| **Ответы** | Таблица отправленных ответов и экспорт |

**Снизу — статус-бар:** состояние Ollama и opencode, прогресс `N / всего`, среднее время ответа модели и текущее сообщение.

## 4. Подключение модели

Бэкенд переключается на вкладке **Управление** в поле **Бэкенд**.

### Ollama (локально)

1. Установите Ollama с [ollama.com](https://ollama.com) и запустите её. Сервер слушает `http://127.0.0.1:11434`.
2. Скачайте модели в терминале:

   ```powershell
   ollama pull qwen2.5:7b-instruct
   ollama pull qwen2.5vl:7b        # нужна для vision-фолбэка
   ```

3. В приложении: **Бэкенд** = `Ollama (локально)` → нажмите **обновить** рядом с моделью → выберите модель из списка.
4. Нажмите **Проверить связь с моделью** — должен появиться ответ модели.
5. Если нужен vision-фолбэк (распознавание вопроса по скриншоту), оставьте включённой галку **Vision-фолбэк** и укажите vision-модель в настройках (`ollama.visionModel`).

Под списком моделей показывается подсказка: если выбранной модели нет в Ollama, её нужно скачать или выбрать другую.

### opencode (CLI)

1. Установите и авторизуйте opencode так, как описано в его документации. Проверка: `opencode --version`.
2. В приложении откройте **Настройки** → `opencode.bin`: оставьте `opencode`, если CLI есть в PATH, или укажите полный путь к `opencode.exe`.
3. **Бэкенд** = `opencode CLI` → **обновить** → выберите модель из списка `opencode models`.
   Модель задаётся в формате `provider/model`, например `opencode/deepseek-v4.1-flash-free`. Пустое значение — модель opencode по умолчанию.
4. Нажмите **Проверить связь с моделью**.

> При использовании облачной модели через opencode текст вопросов отправляется провайдеру модели.

### mock (отладка)

Бэкенд `mock` не требует модели: для вопросов с вариантами отвечает случайным образом, для последовательностей вводит `12345`. Удобно проверить интерфейс и навигацию по тесту.

## 5. Прогон теста

1. Вставьте адрес теста в строку сверху и нажмите **Перейти**.
2. Войдите в тест, дождитесь загрузки первого вопроса.
3. На вкладке **Управление** проверьте бэкенд и модель.
4. При необходимости задайте **Задержку** (пауза перед «Продолжить», по умолчанию 3000 мс) и **Лимит вопросов** (`0` — без лимита).
5. Нажмите **Старт** или `Ctrl` + `Shift` + `S`.

Во время прогона в панели видно: сколько вопросов отвечено, текущий вопрос, последний ответ, уверенность модели и среднее время ответа. Кнопка **Стоп** (или то же сочетание клавиш) останавливает прогон.

Прогон останавливается сам, когда:

- тест закончился (страница результатов);
- на странице больше нет ни вариантов ответа, ни поля ввода;
- достигнут лимит вопросов;
- подряд произошло слишком много ошибок разбора (`automation.maxParseFailures`);
- включён `automation.stopOnLowConfidence` и уверенность модели ниже порога;
- кнопка «Продолжить» не найдена или вопрос не сменился за отведённое время.

> Совет: для первого знакомства поставьте **Лимит вопросов** = `1`–`3`, чтобы проверить, что приложение правильно понимает страницу.

## 6. Типы вопросов

| Тип | Как выглядит | Что делает приложение |
|---|---|---|
| Один вариант | Радиокнопки | Выбирает один вариант, который вернула модель |
| Несколько вариантов | Чекбоксы | Отмечает все варианты, которые вернула модель |
| Текстовый ответ | Поле ввода, вопрос просит число, слово или фразу | Вводит ответ в поле |
| Последовательность | Нумерованные пункты и поле «Ваш ответ:» | Вводит номера пунктов в правильном порядке |

**Последовательность.** Если в вопросе есть нумерованный список и поле ввода, ответ — перестановка номеров `1..N` без пробелов и разделителей. Например, для пяти пунктов правильный порядок «2, 5, 4, 1, 3» вводится как `25413`. Модель получает требование формата со страницы; если она вернула неверный формат, приложение один раз переспрашивает.

**Подсветка.** Перед кликом выбранный вариант или поле подсвечиваются зелёным. В режиме **Dry run** подсветка синяя, кликов нет: можно проверить, что приложение видит вопрос, и перейти дальше вручную.

**Ограничения.** Drag-and-drop, капча и нестандартные виджеты (самописные выпадающие списки, виртуальные клавиатуры) не поддерживаются.

## 7. Настройки

Все параметры меняются на вкладке **Настройки** и сразу сохраняются в `config.json`:

- инсталлятор: `%APPDATA%\TestSolver\config.json`;
- portable: `config.json` рядом с exe.

Любой отсутствующий ключ означает значение по умолчанию. Кнопка **Сбросить всё к умолчаниям** возвращает исходные значения.

| Ключ | По умолчанию | Описание |
|---|---|---|
| `backend` | `ollama` | Кто отвечает: Ollama, opencode или `mock` без модели |
| `ollama.url` | `http://127.0.0.1:11434` | Адрес сервера Ollama |
| `ollama.model` | `qwen2.5:7b-instruct` | Имя модели из `ollama list` |
| `ollama.visionModel` | `qwen2.5vl:7b` | Модель для распознавания скриншота |
| `ollama.temperature` | `0` | Температура генерации, 0–2; `0` — детерминированно |
| `ollama.numCtx` | `4096` | Размер контекстного окна |
| `ollama.keepAlive` | `30m` | Сколько держать модель в памяти |
| `ollama.timeoutMs` | `120000` | Таймаут ответа модели, мс |
| `opencode.bin` | `opencode` | Имя в PATH или полный путь к `opencode.exe` |
| `opencode.model` | `""` | Модель `provider/model`; пусто — по умолчанию из opencode |
| `opencode.timeoutMs` | `180000` | Таймаут ответа CLI, мс |
| `automation.mode` | `auto` | `auto` — всё автоматически; `confirm` — подсветить и ждать ручного клика |
| `automation.delayMs` | `3000` | Пауза после ответа перед «Продолжить», мс |
| `automation.jitterPct` | `30` | Случайный разброс задержки, % |
| `automation.maxQuestions` | `0` | Сколько вопросов пройти; `0` — до конца теста |
| `automation.clickNext` | `true` | Нажимать «Продолжить» автоматически |
| `automation.dryRun` | `false` | Только подсвечивать и логировать, не кликая |
| `automation.questionChangeTimeoutMs` | `15000` | Ожидание нового вопроса после клика, мс |
| `automation.postClickWaitMs` | `1200` | Дополнительная пауза после загрузки, мс |
| `automation.maxParseFailures` | `3` | Сколько ошибок подряд допустить до остановки |
| `automation.stopOnLowConfidence` | `false` | Останавливаться при низкой уверенности модели |
| `automation.minConfidence` | `0.4` | Порог уверенности для предыдущей опции, 0–1 |
| `automation.startUrl` | `""` | Стартовая страница теста для кнопки «Открыть тест» |
| `vision.enabled` | `true` | Включать vision-фолбэк, если текст вопроса не распознан |
| `vision.maxPerRun` | `10` | Максимум vision-вызовов за прогон; `0` — без лимита |
| `vision.saveScreenshots` | `false` | Сохранять скриншоты в папку логов |
| `logging.dir` | `%APPDATA%\TestSolver\logs` | Папка логов; пусто — папка данных приложения |
| `logging.answersJsonl` | `true` | Писать `answers.jsonl` — по строке на каждый вопрос |
| `logging.rotateMb` | `10` | Размер `app.log` до ротации, МБ |
| `logging.level` | `info` | Подробность журнала: `debug`, `info`, `warn`, `error` |
| `ui.panelWidth` | `400` | Ширина правой панели, px; меняется перетаскиванием |
| `ui.theme` | `system` | Тема: как в системе, тёмная или светлая |

### Практические советы

- **Задержка 2000–5000 мс** и разброс 20–40 % выглядят естественнее и дают странице дорисоваться.
- **Медленный сайт:** увеличьте `automation.questionChangeTimeoutMs` до 30000–60000.
- **Пробный прогон:** `automation.maxQuestions` = 1–3, затем снимите лимит.
- **Проверка без кликов:** включите `automation.dryRun`.
- **Ручное подтверждение:** `automation.mode` = `confirm` — приложение подсветит ответ и будет ждать, пока вы сами нажмёте «Продолжить».
- **Слабый компьютер:** возьмите модель 7B и уменьшите `ollama.numCtx` до 2048–4096.
- **Экономия vision-вызовов:** `vision.maxPerRun` ограничивает число скриншотов за прогон.
- **Приватность:** `vision.saveScreenshots` по умолчанию выключен, потому что скриншоты могут содержать персональные данные.

Настройки автоматизации применяются к следующему прогону; текущий прогон использует значения, снятые при нажатии «Старт».

### Флаги командной строки (для продвинутых)

Флаги не сохраняются в `config.json` и действуют только на текущий запуск:

```powershell
TestSolver.exe --backend opencode --model anthropic/claude-sonnet-4
TestSolver.exe --delay 2500
TestSolver.exe --set automation.dryRun=true --set automation.maxQuestions=2
TestSolver.exe --reset ollama.temperature
TestSolver.exe --portable        # config.json рядом с exe
TestSolver.exe --headless        # окно не показывается (проверка запуска)
```

## 8. Ответы и журналы

### Вкладка «Ответы»

Таблица показывает последние 300 записей: номер вопроса, текст вопроса, выбранный ответ (для текстовых вопросов — введённое значение), уверенность модели в процентах и время ответа в миллисекундах.

Кнопка **Экспорт** сохраняет журнал в JSON или CSV (разделитель `;`, кодировка UTF-8). Экспортируются все записи, загруженные в текущей сессии.

### Файлы в папке логов

| Файл | Содержимое |
|---|---|
| `app.log` | События приложения: запуск, нажатия кнопок, ошибки, сохранённые HTML |
| `app.log.1` … `app.log.3` | Архив предыдущих журналов после ротации |
| `answers.jsonl` | По одному JSON на вопрос: текст, ответ, уверенность, модель, время |
| `no-question-*.html` | HTML страницы, на которой не удалось распознать вопрос |
| `lost-question-*.html` | HTML страницы, где вопрос пропал во время прогона |
| `page-*.html` | HTML, сохранённый вручную кнопкой «HTML страницы» |

Кнопка **Папка логов** открывает эту папку в Проводнике.

**Диагностика страницы.** Если вопрос не распознаётся, нажмите **Лог** → **HTML страницы**: файл сохранится в папку логов. Тот же файл сохраняется автоматически при ошибке разбора. По нему можно понять, как устроена вёрстка, и добавить поддержку новой страницы.

## 9. Диагностика

| Симптом | Что делать |
|---|---|
| Статус `Ollama: нет связи` | Запустить Ollama (`ollama serve` или приложение из трея), проверить `http://127.0.0.1:11434/api/tags` |
| `Модель «...» не найдена` | `ollama pull <модель>` или выбрать другую в списке |
| `opencode не найден в PATH` | Указать полный путь к `opencode.exe` в настройке `opencode.bin` |
| `Не удалось найти ни вариантов ответа, ни поля ввода на странице` | Дождаться полной загрузки страницы; проверить, что тест открыт, а не список тестов; сохранить HTML страницы |
| `На странице больше нет вариантов ответа — остановка` | Возможно, тест завершён или сменился тип вопроса; проверить `no-question-*.html` |
| `Вопрос не сменился за отведённое время — остановка` | Увеличить `automation.questionChangeTimeoutMs`; проверить, что кнопка называется «Продолжить/Далее/Следующий» |
| `Кнопка «Продолжить» не найдена — остановка` | Кнопка называется иначе или скрыта; сохранить HTML страницы |
| Текстовое поле не заполняется | Поле должно быть видимым `input` или `textarea` и не быть поиском/логином; проверить по HTML |
| Ответ выбран, но вопрос не сменился | Включить `automation.dryRun` и проверить вручную; увеличить задержку |
| `Много ошибок подряд` | Модель возвращает неверный формат; сменить модель или увеличить `automation.maxParseFailures` |
| Остановка «низкая уверенность модели» | Отключить `automation.stopOnLowConfidence` или снизить `automation.minConfidence` |
| Модель отвечает очень медленно | Модель 7B вместо крупной, меньше `ollama.numCtx`, закрыть лишние программы |
| SmartScreen не даёт запустить | «Подробнее» → «Выполнить всё равно»; для распространения нужен код-сертификат |
| Portable долго стартует | Это распаковка во временную папку; антивирус может замедлить первый запуск |
| Ответы неверные | Модель слабая для предмета: попробуйте более крупную локальную или облачную модель через opencode; проверьте `answers.jsonl` |

Если ничего не помогло, приложите к вопросу `app.log` и сохранённый HTML страницы — по ним видно, на каком шаге всё остановилось.

## 10. Приватность и ограничения

- Всё работает локально: вопросы, ответы и журналы остаются на компьютере.
- Ollama не отправляет данные наружу. При использовании **opencode** с облачной моделью текст вопросов уходит провайдеру модели.
- Скриншоты (если включены) и HTML страниц могут содержать персональные данные — храните папку логов соответственно.
- Не поддерживаются drag-and-drop и нестандартные виджеты.
- Автоматизация прохождения тестов может нарушать правила учебного заведения. Ответственность за использование лежит на пользователе.
